# 🩺 ash MedBot

یک ربات یادآور دارو برای تلگرام ساخته‌شده با **Python** و **python-telegram-bot**.

## 🚀 امکانات
- اضافه کردن یادآوری دارو با دستور `/add`
- نمایش تمام یادآوری‌ها با `/list`
- یادآوری خودکار در زمان مشخص‌شده
- دکمه تست فوری برای بررسی عملکرد
- ذخیره‌ی اطلاعات در دیتابیس SQLite
- طراحی امن با استفاده از `.env`
